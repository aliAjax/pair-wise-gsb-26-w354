# hxwl-12 心理咨询个案记录 · 联合会谈记录台

两位咨询师同场会谈的协同记录：私密观察 → 点名分享 → 共同草稿双方确认 → 正式纪要（留痕可回退）→ 逐条过滤后导出。

## 技术栈

React + Vite + TypeScript + CSS，数据通过 localStorage 持久化（无后端）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 工作流程与权限规则

1. **私密观察区（甲 / 乙各一）**
   - 观察默认仅作者本人可见；右上角切换身份可模拟另一位咨询师登录，对方私密区显示为锁定占位，不展示数量与原文。
   - 可标记「涉及来访者亲属」或「涉及未经同意第三人」；带标记的段落强制留在私密区，分享按钮禁用。
2. **点名分享 → 共同草稿**
   - 作者点击「点名分享给对方」后，观察才复制为共同草稿段；分享人自动勾选本人确认，等待另一方确认。
   - 每段需甲、乙分别勾选确认；任何一方编辑草稿措辞都会使双方确认失效，须重新确认。
   - 未全部确认的草稿可由分享人撤回到私密区；已入正式纪要的观察不可从源头删除。
3. **正式纪要**
   - 仅收录双方均已确认的段落；首次生成后再次更新必须填写修改原因。
   - 也可直接修订当前纪要，保存时旧版本、修改原因、操作人与时间全部留档；历史版本只读，可在填写原因后回退（回退本身生成新版本，不改写历史）。
   - 待确认段落持久化保存，重新打开页面顶部横幅与草稿区仍会提示。
4. **导出正式摘要（逐条过滤）**
   - 正文只含当前正式纪要版本；过滤台账分三类逐条列示：私密保留（亲属 / 未经同意第三人）、草稿待确认、未点名分享，并对每条写明过滤原因。
   - 他人的私密条目在台账中遮蔽原文（仅本人可见原文与原因），导出为带 BOM 的 UTF-8 .txt，可复制或下载。

## 代码结构

- `src/types.ts`：观察 / 草稿段 / 纪要版本等领域模型
- `src/store.ts`：localStorage 持久化、领域操作（分享、确认、生成、修订、回退）、过滤台账与导出文本
- `src/components/PrivateZone.tsx`：两位咨询师各自的私密观察区
- `src/components/SharedDraftZone.tsx`：共同草稿、逐段确认与纪要生成
- `src/components/MinutesZone.tsx`：正式纪要、版本记录与回退
- `src/components/ExportModal.tsx`：正式摘要预览与逐条过滤台账
